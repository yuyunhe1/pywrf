# 界面与操作体验改版验收

日期：2026-11-06。产品修改限于新版前端；后端接口和数据库结构不变。

## 已交付

- 紧凑品牌栏；左右面板可收起、拖动调宽和键盘调宽；布局本地记忆与恢复默认。
- 桌面默认 320/360px，范围 280–480px，中央地图至少 400px；小屏单侧抽屉通过按钮切换。
- 区域定位常展开；飞行参数独立，高级设置默认折叠，主要操作固定在面板底部。
- 通航结论、起飞与到达、未来窗口前置；四项核心指标、默认收起的详情、14px 正文和至少 12px 辅助信息。
- 最近窗口与起飞区间长度；无数据不显示虚假零值；当前起飞和所选起飞判断分别标明。
- 历史名称搜索和来源/高度/里程信息；同名记录按 ID 回放及导出。
- 保存和导出分离；重复提交保护；保存失败保留路线；迟到的保存响应只关联提交时的几何版本。
- 图例、地图控件、航线居中和底部工具栏使用当前布局尺寸；回放详情收纳，工具栏高度实测避让。
