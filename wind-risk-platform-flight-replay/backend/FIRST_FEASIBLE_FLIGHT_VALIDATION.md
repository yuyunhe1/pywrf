# 首条验收航线结束搜索与自动回放

> 此记录保留首解即结束模式的历史验收，兼容 API 仍支持该模式。当前页面改为两秒分段绘制期间
> 并行改进，变化处重绘，完成后正常结束并回放。最新记录见
> [分段并行改进验收](SEGMENT_DISPLAY_COMPARISON_VALIDATION.md)。

2026-11-15，仅新版平台。页面人工验收由用户进行，不使用 computer-use 或浏览器自动化。

## 当前行为

- 三种可见算法提交 `stop_on_first_feasible=true`，普通规划任务和指定时间推荐工作流均支持。
  默认兼容值为 false，旧脚本仍可选择继续比较候选，隐藏 V3 不变。
- 局部正向搜索材料可提前按 UTC 十分钟边界累计显示蓝色粗实线，不再等完整候选或三十秒。
  只画已经形成的完整时间段，不虚构后续连接。预览使用独立展示状态，不写入正式路径、
  通航结论、保存或窗口。底图匹配同一批次、高度及帧，绘制确认后才更新蓝线和标签。
- 同一次预览只追加一个分支，不因排序、重复进度、正式结果或窗口刷新重播。仅显式失效
  可替换预览分支，未确认可行性的分支不被武断声明为不可行。窗口请求不产生搜索进度。
- 首条完整路径仍经修整、原始网格接触风况、全程重计时及独立航程分析；验收失败继续搜索。
  通过后协调器正常返回 `stop_reason=first_feasible`，停止候选比较，取消双向扩展、清空树和
  待验收队列，回收工作进程租约。持久工作进程可以空闲保留，不继续为该任务计算。
- 前端立刻退出分段预览，采用同一份完整已验收 profile 并自动播放。无需等三十秒、剩余动画、
  窗口或首次底图网络请求。底图慢时飞机仍前进，风场实际绘制后才更新底图时间。
  重复终态响应不会再次发布或自动重播；窗口返回不会重置已选航程。
- 无首解的指定时刻仍使用原六十秒机制及未来方案；未来方案继续显式采用，不自动改起飞时间。
  数据不足、取消、超时、资源保护及旧响应隔离沿用现有机制。
- 缓存命中先全程复核，再自动回放。切换策略或算法后，不用其他策略或算法的缓存路径抢占首解。
  固定路径窗口独立计算，不再搜索更优几何；只有完整路线可保存和导出。

首条可行解不是全局最优路线，策略通过原有评分与搜索次序影响首解。本次未更改风速／切变
硬阈值、策略权重、十分钟原生 WRF、GFS 时间模型、AGL 或资源上限。

## 人工验收

1. 重新加载新版页面，规划一条较长航线。搜索材料足够时蓝线逐段追加，不反复从起点绘制，
   无新工具栏。若首解很快到达，直接进入回放，不人为拖慢首解展示以播放动画。
2. 首条全程可飞路线出现后，确认飞机自动运动、规划任务结束，后台不继续换线。
   窗口完成或刷新时播放进度保持，粒子背景仍每飞行三十分钟更新。
3. 同一端点切换三种策略或算法，检查仍按所选配置搜索；同配置缓存命中后复核并自动回放。
4. 搜索中取消、改参数或重新规划，确认旧蓝线不继续增长；缺数据不出现可保存的假路线。
5. 回归保存／重载、曲线红色定位、倍速／暂停及窗口显示。人工结果尚未登记，不声称已通过。
