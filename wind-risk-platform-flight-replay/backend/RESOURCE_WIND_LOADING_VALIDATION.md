# 适度资源限制与风场加载优化

日期：2026-11-11。仅修改新版平台；未修改旧版平台、服务器 WRF 生产配置或原始 V3 源码。

2026-11-12 后续交付：缓存合计仍为每来源 64MB，现分为 48MB 解码和 16MB 编码，
前端默认生产构建并使用无损统一数据包。最新测试、实测和运行版本见
[临时公网风场加载优化验收](PUBLIC_WIND_LOADING_VALIDATION.md)。本文保留此前阶段的测量记录。

## 已生效的限额

| 项目 | 默认设置 |
| --- | --- |
| 正反向到达标签 | 合计 600000，原固定上限 180000 的约 3.3 倍；按搜索批次检查 |
| 搜索子进程 | 最多 4 个，两个起飞时刻各用一对正反向进程 |
| 工作流、排队容量 | 同时一个工作流，容量 8；未来起飞尝试最多两个并行 |
| 系统可用物理内存余量 | 2048MB；不足时停止新扩展并保留已验收结果 |
| 搜索／协调进程常驻内存 | 达到 2048MB 时触发协作式停止，读取当前值而非历史峰值 |
| 数值库线程 | 启动脚本默认 OMP、OpenBLAS、MKL、NumExpr 各 1 线程，防止子进程内再次大量开线程 |
| 后台显示网格缓存 | 每进程、每数据源 64MB；WRF 最多 48 项，GFS 最多 24 项，容量先达到则先淘汰 |
| 页面天气缓存 | 请求缓存 48MB／24 项，回放缓存 16MB／8 项；数组按每项 16 字节保守估算 |
| 天气请求 | 页面合计最多 2 个活跃请求，预加载最多占 1 个；最多 8 个排队请求 |
| 回放预加载 | 仅后续两个实际需要显示的时刻，粒子模式按 30 飞行分钟选帧 |
| 粒子显示 | 一套共享风场；最多 6000 粒子、250000 个屏幕投影采样位置 |

内存限制是批次和检查点保护，不是操作系统的硬配额；正在显示的画面、渲染场和任务持有的
不可变快照不计入显示缓存容量。现有完整预报、全部原始空间格点、风险规则和 7200 秒父任务
预算继续使用；资源受限不能表述为已经证明不存在可行路线。原时刻首解仍最多查 60 秒。

## 加载与绘制

- WRF 并发请求同一个网格时共享一次解码；缓存键含文件修订、产物哈希、来源目录、高度与范围。
  清除缓存后，迟到的旧解码不能重新写入。未变化的十分钟同步保留热缓存。
- 页面按预报修订缓存单时刻结果，回放按不可变数据集 ID 与有效时刻缓存。相同请求合并，
  取消一个读取者不会取消其他读取者；快速切换取消过期前台请求，当前画面优先于预加载。
- 飞机每 500 毫秒推进，不等待风场 HTTP 请求。下载中继续标明实际底图时刻和加载状态；
  暂停按钮保持可用。缺帧仍显示数据不足，不制造原生帧或修改通航判断。
- 五套逐风级的粒子引擎改为一套共享网格，按原阈值确定颜色，保留图例筛选。投影计算按约
  12 毫秒的小批次执行，切换、移除时取消旧计算。屏幕采样限制只影响绘制，不抽稀气象源数组。
- 热力图更新复用画布；风场使用浅引用并按对象替换监听，避免遍历整幅响应式数组。
- 新临时公网域名加入 Vite 允许的 `.trycloudflare.com` 域名范围。许可文本从开发监听中排除，
  避免 Windows 新增静态许可文件时触发文件监听错误。生产构建包含改编组件的许可文本。

粒子引擎的独立改编副本为 `frontend/src/layers/SharedWindy.js`，来源 leaflet-velocity 2.1.4
的 `src/js/windy.js`。原件 SHA256 为
`6ab71b7f590f7f490e12c21632968efdbe888ca02c8e61b9486734f7941d2acd`，原依赖文件未修改。
许可原文保留于 `SharedWindy.LICENSE.md` 和构建产物的 `licenses/leaflet-velocity.txt`。

## 验证结果

- 后端完整回归：378 passed、1 skipped；随后对 GFS 缓存、原生同步、资源限制和任务管理的最新
  修改再次定向回归 70 项全部通过。覆盖容量淘汰、请求合并、清理中的迟到响应、进程当前内存、
  无变化同步保留缓存、内存受限保留已验收路线、完整区域及原生十分钟数据。
- 前端最终回归：136 passed；生产构建通过。覆盖并发、优先级、单读取者与全部读取者取消、
  原生预加载、慢网络下继续推进、缓存复用与版本失效。Vite 构建有原依赖 PURE 注释提示，无构建错误。
- 真实原生 WRF 浏览器检查：20 项通过。使用约 49.65km 的未保存固定路径，验证单一粒子场、
  精确风级边界、图例筛选、原始全部 U/V 值一致、红色曲线定位、30 分钟背景保持、预加载命中、
  人工延迟下持续播放、真实底图时刻标记及正常历史记录不变；无浏览器运行错误。
- 本机单次浏览器记录：返回已缓存单时刻约 19.6ms、天气 HTTP 请求 0 次；首次访问另一个页面
  未缓存时刻约 86.4ms。共享粒子场改造前后的同类预加载回放控制器换帧分别约 1217.4ms、33.8ms。
  这些是单次检查，不是统计分位数，也不代表完全冷盘或公网首次访问耗时；投影场分批完成。
- 浏览器采样时粒子 5184 个、有效屏幕投影采样 25176 个；请求缓存约 2.26MB，回放缓存约 1.13MB，
  均在限额内。
- 本机、前端代理、临时公网均返回有效限额。一次真实单时刻接口测量，本机 wind／heatmap
  约 25.9／36.7ms，公网约 1.97／1.24 秒，公网响应已有 gzip。公网新时刻仍受网络影响，
  本期主要减少重复等待及渲染阻塞，没有承诺公网首帧耗时上限。
